# 源码与许可边界

## 对应交付源码

待发布的 Release `os44-qpace-force-9838` 计划附 `OS44_FORCE_9838_source.tar.gz`，包含构建9838使用的完整内核工作树与BakaSU源码。归档已在本地准备，但上传遇到超时，尚未公开提供下载。保留上游LICENSES、COPYING、版权头和SPDX。源码归档不含.git历史、编译缓存、手机日志或个人签名凭据；Linux上游自测目录中的公开测试夹具原样保留。

Linux/Android、BakaSU、SUSFS及第三方文件各自许可证仍有效。本仓库不以一个新许可证覆盖这些既有文件。新增构建入口与研究代码按其SPDX标识或目录说明处理。

格式参考cctv18仓库，但没有复制其workflow或二进制库。没有承诺其广告中的特性、编译时间或其他机型兼容性。

## 原厂二进制依赖

当前可启动包继续依赖手机已有的小米／高通模块；本项目没有恢复全部闭源厂商驱动。不发布厂商固件镜像或模块全集，不修改原厂模块CRC、KCFI或强制加载标志。

`lib/btf/stock_Image.btf` 是用于split-BTF引用兼容的类型元数据；`module_inventory.json` 仅保存已冻结模块身份hash、类型引用和字符串偏移，不包含可执行模块。该构建过程保持语义匹配，不等于恢复了全部厂商原始C声明。

## 实验性源码

`research/ufs/` 是独立的UFS源码重建集群，不参与9838交付内核。其完整平台probe、注册生命周期、私有类型兼容仍有缺口，不能替换正在运行的原厂UFS驱动。

`zram_patch/next/` 是用户要求的下一版容量映射；默认扩展档位和关闭策略不变，尚未部署。
