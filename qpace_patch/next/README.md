# 下一版 QPaCE 名称

按用户要求把显示名称从 `qpace-canoe` 改为 `qpace-hgn284`。

- Crypto API 算法名、driver name、模块别名、强制选择名称与日志一并修改。
- 硬件编解码、寄存器、DMA 路径和内部 `canoe_*` 硬件符号保持不变。
- `kernel/` 是修改后的两个真实源码文件，`name-hgn284.patch` 从当前9838源码生成，在内核根目录使用 `git apply` 接入。
- 已交付9838和本仓库 `source/` 历史摘录仍保留原名；下一次内核编译与刷入后，系统才显示新名称。
- 下一版容量匹配改动仍按 `zram_patch/` 单独接入。不要对当前正在使用的swap热改名或重置。

本次只准备源码，无新构建、测试或手机操作。
